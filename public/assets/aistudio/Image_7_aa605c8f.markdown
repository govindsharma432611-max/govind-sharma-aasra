## Brand & Style

This design system defines an elite international digital engineering studio and high-craft brand agency. It merges rigorous software architecture with expressive creative direction, establishing an aesthetic rooted in high-end technological minimalism with controlled kinetic energy.

The aesthetic fuses deep spatial discipline with expressive typographic tension:
- **Atmospheric Depth:** Deep-space fields punctuated by concentrated violet spectral glows, crystalline glass tiers, and precise hairline boundaries.
- **Architectural Typographic Scale:** Brutalist geometric headlines set against razor-sharp functional body copy, creating an editorial, high-production posture.
- **Controlled Kinetic Restraint:** Interactions leverage low-friction transitions, magnetic hover behaviors, and directional arrow micro-movements to convey computational precision.

## Colors

The palette operates primarily in a dark surface environment. Color is deployed as controlled illumination rather than decorative surface tinting.

### System Palette Roles
- **Primary Violet (`#6327FB`):** High-energy electric purple reserved for key call-to-actions, primary interactive focus states, critical metric callouts, and active navigational indicators.
- **Deep Midnight (`#1D0D42`):** Structural foundation for elevated surfaces, containment wrappers, layered cards, and secondary accent backplates.
- **Soft Lavender (`#A786FC`):** Atmospheric light emission, supporting metadata, interactive hover states on dark surfaces, and subtle vector framing.
- **Near Black (`#050404`):** Global canvas background. Anchors all visual hierarchy and provides uncompromised contrast for radiant accents.
- **Pure White (`#FFFFFF`):** High-contrast primary copy, hero headlines, key brand iconography, and stark button surfaces.
- **Light Grey (`#EAEAEA`):** Secondary editorial copy, structural separators, and inactive input borders.

### Surface Color Mapping
- **Canvas / Root:** `#050404`
- **Surface Elevation 1 (Card / Container Base):** `rgba(29, 13, 66, 0.40)`
- **Surface Elevation 2 (Elevated Flyouts / Menus):** `rgba(29, 13, 66, 0.75)`
- **Surface Elevation 3 (Active Glass / Highlights):** `rgba(167, 134, 252, 0.08)`
- **Hairline Dividers & Ghost Borders:** `rgba(255, 255, 255, 0.08)` to `rgba(167, 134, 252, 0.20)`
- **Text Primary:** `#FFFFFF`
- **Text Secondary:** `rgba(234, 234, 234, 0.70)`
- **Text Muted:** `rgba(234, 234, 234, 0.45)`

## Typography

Typographic hierarchy sets an intentional rhythm between the technical structuralism of **Space Grotesk** and the neutral clarity of **Manrope**.

- **Editorial Treatment:** Hero displays and section title cards may feature selective italicization on key nouns or industry metrics to inject bespoke editorial flair.
- **Uppercase Metadata:** `label-lg` and `label-md` levels default to uppercase with tracking (`letter-spacing: 0.06em` to `0.08em`) for categorization tags, technical spec keys, and index numbering (e.g., `01 / PLATFORM ARCHITECTURE`).
- **Body Rhythm:** Never set body text below 14px for general copy. Paragraph lines should strictly limit measure to a maximum of 65 characters to preserve legibility against deep spatial canvases.

## Layout & Spacing

The layout model uses a strict 12-column responsive fluid grid with deliberate architectural whitespace.

### Grid Anatomy
- **Desktop (1280px+):** 12 columns, `gutter-desktop: 2rem` (32px), `margin-desktop: 4rem` (64px), maximum content wrapper of `1440px`.
- **Tablet (768px – 1279px):** 8 columns, `gutter: 1.5rem` (24px), `margin-tablet: 2.5rem` (40px).
- **Mobile (&lt; 768px):** 4 columns, `gutter: 1rem` (16px), `margin: 1.25rem` (20px).

### Section Rhythms
- Vertical rhythm between flagship landing blocks is spaced generously using `space-3xl` (96px) on mobile and scaled to 140px–180px on desktop to create an expansive, high-end studio presence.
- Structural card layouts leverage asymmetric column spans (e.g., 7-column primary visual paired with 5-column architectural metadata).

## Elevation & Depth

Depth is established through translucent atmospheric layers, frosted glass filtration, and radial purple light refraction rather than standard diffuse drop shadows.

### Atmospheric Surfaces
1. **Base Floor (Level 0):** Pure black (`#050404`). Ground state.
2. **Backdrop Blurs (Level 1):** `backdrop-filter: blur(16px)` combined with semi-transparent surfaces (`rgba(5, 4, 4, 0.75)`) and hairline border borders (`rgba(255, 255, 255, 0.08)`).
3. **Elevated Panels (Level 2):** Semi-opaque Midnight base (`rgba(29, 13, 66, 0.45)`) combined with a dual-layer edge:
   - Outer: `1px solid rgba(167, 134, 252, 0.15)`
   - Inset: `inset 0 1px 0 0 rgba(255, 255, 255, 0.12)`
4. **Interactive Floating Cards (Level 3):** On hover or selection, panels shift upward by `2px` and project a concentrated ambient spectral violet bloom:
   - Box shadow: `0 20px 40px -15px rgba(99, 39, 251, 0.35), 0 0 20px -2px rgba(167, 134, 252, 0.15)`
   - Border transitions to: `rgba(167, 134, 252, 0.40)`

### Ambient Lighting Rules
- Violet glows (`#6327FB`) are localized as non-interactive backdrop ambient light using blurred radial gradients (`filter: blur(120px); opacity: 0.15` to `0.25`).
- Never use uniform solid shadows or default gray drop-shadows.

## Shapes

The geometric strategy uses controlled micro-curvature (`0.5rem` / 8px default) for data surfaces and content cards, balanced with dynamic pill structures (`9999px`) for interactive triggers, utility tags, and micro-navigation.

- **Standard Cards & Modals:** `rounded` (8px) or `rounded-lg` (16px) for spacious structural elements.
- **Action Triggers & Status Badges:** Pill-shaped (`rounded-full`) for high-contrast visibility and tactile affordance.
- **Tab Indicators & Segments:** Rounded micro-capsules (`rounded-md`, 6px) nested within a pill-shaped container track.

## Components

### Buttons & Interactive Controls
- **Primary Studio Button:** Pill-shaped (`rounded-full`), solid `#6327FB` fill, `#FFFFFF` text (`label-lg`). Includes an embedded trailing arrow glyph enclosed in an inner micro-circle. On hover, the arrow shifts `4px` top-right while the button casts a `0 0 25px rgba(99, 39, 251, 0.5)` violet bloom.
- **Secondary Ghost Button:** Pill-shaped with a `1px` border of `rgba(255, 255, 255, 0.20)` and transparent fill. On hover, transitions to `rgba(29, 13, 66, 0.60)` fill, `#FFFFFF` text, and `rgba(167, 134, 252, 0.50)` border.
- **Tertiary Link:** Inline `Space Grotesk` medium text, underlined with a subtle offset purple hairline that expands from width `0%` to `100%` on hover.

### Navigation Header
- **Sticky Backdrop Nav:** Suspended pill or edge-to-edge floating layout with `backdrop-filter: blur(20px)`, background of `rgba(5, 4, 4, 0.80)`, and a bottom hairline stroke `rgba(255, 255, 255, 0.06)`.
- Links use `label-lg` in `#EAEAEA` transitioning to `#A786FC` on hover. Active routes feature a micro violet dot (`4px`) anchored below the label.

### Project & Service Cards
- **Asymmetric Portfolio Cards:** Deep Midnight translucent foundation (`rgba(29, 13, 66, 0.35)`), bordered with `1px rgba(255, 255, 255, 0.08)`. Layout spans dynamically (e.g., odd items 7-columns, even items 5-columns).
- **Interactive Badges:** Pill-shaped tags (`label-md`) with `rgba(167, 134, 252, 0.12)` background, `1px solid rgba(167, 134, 252, 0.30)`, and `#A786FC` text.

### Interactive Service Category Switchers & Tabs
- Outer container structured as an enclosed frosted pill track (`rgba(255, 255, 255, 0.03)` with `1px solid rgba(255, 255, 255, 0.06)`).
- Active item displays a smooth sliding pill background (`#1D0D42` with border `rgba(167, 134, 252, 0.30)` and subtle purple drop glow).
- Typography switches from muted gray (`rgba(234, 234, 234, 0.50)`) to stark `#FFFFFF`.

### Form Controls & Input Fields
- Dark structural wells (`rgba(29, 13, 66, 0.25)`) with an inactive hairline border (`rgba(255, 255, 255, 0.12)`).
- On focus: Border highlights to `#6327FB` accompanied by a localized inner rim glow (`box-shadow: 0 0 0 3px rgba(99, 39, 251, 0.20)`).
- Inputs use `body-md` in `#FFFFFF`, with placeholder text rendered in `rgba(234, 234, 234, 0.30)`.

### Multi-Column Studio Footer
- Deep canvas area flanked by a wide top border (`1px solid rgba(255, 255, 255, 0.08)`).
- Features a massive signature headline, an interactive newsletter field with integrated submission pill, and structured multi-column navigation organized by category code index (e.g., `INDEX / 01`, `INDEX / 02`).
